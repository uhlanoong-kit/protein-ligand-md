# Contributing

Contributions should preserve scientific traceability and reproducibility.

1. Create a focused branch.
2. Describe the scientific or software reason for the change.
3. Add or update tests for reusable Python code.
4. Run `python -m pytest`.
5. Document changed selections, units, parameters, or assumptions.
6. Do not commit trajectories, private data, licensed software, or unverified
   parameter files.

Bug reports should include the command, software version, concise error,
relevant input metadata, and attempted fixes.

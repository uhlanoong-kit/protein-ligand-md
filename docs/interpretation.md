# Interpretation template

Complete this document only after validation.

## Verified observations

Report measurements with system, replica, time window, atom selection, units,
and uncertainty.

## Comparison

Describe which differences are consistent across replicas. Separate global
protein stability from local pocket or ligand behavior.

## Scientific interpretation

Explain plausible structural meaning without converting correlation into
causation.

## Alternative explanations

Consider construct differences, starting coordinates, protonation,
parameterization, finite sampling, and analysis-selection effects.

## Conclusion

State only conclusions supported by validated project observations.

# Public release checklist

## Repository quality

- [ ] repository URL added to `CITATION.cff`
- [ ] README links and commands tested
- [ ] Mermaid diagram renders correctly on GitHub
- [ ] CI passes on the default branch
- [ ] license and citation metadata reviewed
- [ ] no placeholder usernames, fake results, or unsupported claims

## Scientific quality

- [ ] study question and replica design are chemically defensible
- [ ] structure audit is complete
- [ ] parameterization is documented and validated
- [ ] simulation settings are justified
- [ ] replicas are analyzed separately
- [ ] uncertainty and limitations are reported

## Privacy and licensing

- [ ] no private BM3 files or lab-provided parameters
- [ ] no credentials, personal paths, or server addresses
- [ ] no licensed software or restricted tutorial content
- [ ] third-party structures, software, and methods are cited
- [ ] large generated files are excluded

## Presentation

- [ ] first screen explains the question and why it matters
- [ ] one structure image and one workflow diagram are visible
- [ ] verified result figures have informative captions
- [ ] project status is accurate
- [ ] contact/profile link is intentional
